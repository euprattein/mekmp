### ティア
通常のMekanismの電動ポンプに発展ティアインストーラーを使用することで、発展電動ポンプにできます。<br>＊クラフトでは現状作れません。そのうち対応するかもしれないし、しないかもしれません。
ティアが上がるごとに、汲み上げ量は4倍、電力消費量は2倍になります。（サーバーのconfigで変えられるかも？）
### アップグレード
スロットの位置を変えていますが、通常通り使えます。代わりにバッテリーのスロットは消しました。使わないでしょ。
